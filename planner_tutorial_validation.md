# Planner Tab and Feature Tour Validation

The Custom Builder now displays a compact **Training Day** tab instead of an always-open drafting dock. Opening the tab exposes its Session Planner only on request and provides explicit controls to move the panel to the opposite screen edge or close it again. The builder remains usable when the tab is collapsed.

Live validation confirmed that the tab opens an on-demand planner with day, loadout, draft, move, and close controls. The Guide trigger remains available at the workspace edge for the post-quiz feature tour.

The Guide was verified in the live workspace: it opens a six-step overlay with a clear first step, progress markers, skip control, and contextual navigation through Command Center, recommendations, Custom Builder, Body Lab, Movement Atlas, and Exercise Genome.
