# First-Visit Onboarding Specification

Gym Optimizer opens with a **blank planning canvas** rather than the command center. The first screen positions the system as an athlete and coach workspace, then offers a brief, skippable tutorial before collecting the inputs that personalize the app.

| Step | User decision | Workspace effect |
| --- | --- | --- |
| 1. Quick tour | Review the four product areas or skip | Explains Command Center, Movement Atlas, Body Lab, and Workout Builder in under one minute. |
| 2. Training outcome | Athleticism, muscle growth, max strength, or capacity | Sets the recommendation and prescription priority. |
| 3. Training frequency | Two, three, four, or five-plus days | Sets the plan cadence and session-volume guidance. |
| 4. Sport lens | Choose from the twenty researched sports | Loads the correct twenty-movement research profile. |
| 5. Stack choice | Build a custom stack, use an optimizer stack, or skip | Opens the Custom Builder, generates a sport-aware session, or starts a minimal editable workspace. |

The choice is saved locally so returning users arrive at the personalized command center. A visible **Rebuild plan** action reopens onboarding, and **Tour** replays the tutorial. The suggested stack is a transparent starting point generated from the selected sport, goal, and schedule; it is never presented as medical advice or a guaranteed performance outcome.

The visual update uses a **performance-blue hierarchy**: midnight navy for the console, cobalt blue for primary selection and navigation, pale blue for supporting surfaces, and restrained vermilion only for selected transfer-grade and caution signals.
