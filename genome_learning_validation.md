# Exercise Genome Learning Validation

The live Exercise Genome workspace shows full labels for Hypertrophy potential, Strength expression, Power expression, Stability demand, Mobility demand, Stimulus-to-fatigue ratio, Technical skill demand, and Practicality. Each score tile and each matching legend item is exposed as a clickable control.

The fingerprint now includes visible axis labels and a 0–100 interpretation statement that clarifies the values are relative standardized estimates rather than universal verdicts.

The live Stability demand control opened a learning panel with the term’s definition, the model inputs considered, a score-interpretation statement, and an explicit standardized-estimate boundary. The close control returned the interface cleanly to the fingerprint.
