# Information Architecture Refresh

## Primary Rule

Each workspace answers **one primary question** before exposing supporting evidence. Secondary lists, scientific rationale, and programming diagnostics appear only after the athlete asks for more detail.

| Workspace | Primary task | Above-the-fold content | Deferred content |
|---|---|---|---|
| Command Center | Decide the next session | One movement, one session action, one concise rationale | Additional priority blocks and research evidence |
| Recommended Workouts | Choose a session | Three candidate sessions with grade, duration, and focus | Full exercise explanations and coverage notes |
| Custom Builder | Build or adjust a workout | Session exercise list, add control, concise health status | Weekly map, redundancy details, prescription notes |
| Body Lab | Understand engaged anatomy | Selected movement and selected muscle | Full callout list and functional anatomy notes |
| Movement Atlas | Inspect a sport action | Search, selected action, prime movers, recommended support | Full movement list, joint actions, sources, and cautions |
| Exercise Genome | Compare exercise qualities | Fingerprint and one-sentence decision summary | Muscle mechanics, fatigue, practicalities, and learning panels |

## Reading Rhythm

Workspace headers use one title, one supporting sentence, and one action. Body text defaults to readable 14–16px type with short line lengths. Uppercase technical labels remain available as low-emphasis cues, but are not used as the primary means of navigation.

## Progressive Disclosure

Long evidence, exhaustive lists, and diagnostic details use explicit **Details**, **Why this matters**, or **See all** controls. Visible lists begin with three to six useful items and disclose more only on demand. Mobile retains the same context through expandable rows rather than hiding rationale entirely.

## Live Validation

The refreshed Movement Atlas now opens with seven actions instead of the full twenty-item list, five family filters instead of the entire family set, and a focused action card that surfaces only the body action and prime movers. Stabilizers and transfer reasoning are intentionally placed behind **Why this action matters**, while clear controls expose the full action and filter lists when required.

The live interaction confirms the disclosure expands cleanly only after selection, keeping the initial action scan focused while retaining the deeper stabilizer and transfer evidence for users who request it.
