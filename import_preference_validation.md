# Import Navigation and Home Preferences Validation

The Home workspace now exposes clearly labelled selectors for sport, training goal, and available days per week. The verified controls retain the existing context-update behavior, including sport-linked recommendation refresh and frequency-linked split availability.

The revised paste-plan dialog uses a scrollable page-safe overlay plus an independently scrollable parsed-preview region. Its review controls, candidate selectors, cancel action, and load action remain available while inspecting a multi-day routine.

The refreshed workspace confirms that unauthenticated athletes now see a dedicated **Sign in to save workouts** control in the navigation rail. This is the intended gate before per-set weight and repetition data can be saved to account-scoped session history.

Training Days validation confirms that selecting **Start session** reveals a dedicated sign-in panel explaining the stored set-by-set workflow. It does not expose the former local-only completion behavior; the primary action is correctly labelled **Sign in to start**.
