# Loadout and Split Draft Validation

The live custom builder now shows a dock with three day chips for a three-day plan: Push, Pull, and Legs. It also exposes Athletic Power, Strength Foundation, Hypertrophy Volume, Capacity Circuit, and Sport Transfer loadout modes, plus a dedicated Draft This Session action. The Body Lab’s simplified detailed map and the existing custom-builder exercise controls remain reachable from the same workspace.

The TypeScript check and production build completed successfully after the change. The dock is intentionally fixed to keep day switching available while athletes browse a long custom workout or the exercise finder.

The Legs day was selected and drafted in the live workspace. The stack changed from the original rotation-focused session to a distinct loadout containing landmine thrusters, landmine split jerks, a conventional deadlift, back squat, reverse lunge, and barbell hip hinge, confirming that the split choice materially changes the generated session.
