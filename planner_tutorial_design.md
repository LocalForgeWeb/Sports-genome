# Planner Tab and Feature Tour Design

## Planner Controls

The fixed full-width Training Day dock becomes a compact floating tab. It is collapsed by default, can be dragged to a preferred screen edge, and expands only when the athlete explicitly opens it. The expanded panel contains the existing day, loadout, and draft controls, with a visible close control. Its saved position is bounded to the viewport and restored from local browser storage.

## Post-Quiz Tour

Completing the quiz opens a concise six-step guide. Each step explains a distinct workspace and directs the athlete toward a clear first action: Command Center, Recommended Workouts, Custom Builder, Body Lab, Movement Atlas, and Exercise Genome. The tour is skippable, keyboard-friendly, and can be reopened later from a small Guide control. It never blocks onboarding or forces athletes to finish the tour before using the app.
