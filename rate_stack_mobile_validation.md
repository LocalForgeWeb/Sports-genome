# Rate Stack and Mobile Training Days Validation

Rate Stack uses only the muscle requirements of the selected split. A Push day is evaluated against pectoralis major, anterior and lateral deltoids, triceps brachii, and serratus anterior; pull, leg, upper, lower, full-body, and sport-transfer days use their own separate requirement lists. The analysis displays a transparent catalog-tag estimate, highlights gaps, and recommends catalog exercises that address the largest relevant gaps. It does not display unrelated muscles in a split rating.

The mobile exercise prescription controls now move in normal document flow instead of overlaying the title and prescription. Order buttons receive their own compact row, exercise identity and removal controls occupy separate grid positions, and RPE, rest, completion, and notes wrap into full-width or two-column touch-friendly controls.

The split-stack unit test, the complete test suite, the TypeScript check, and the production build all pass.
